# Shared HW Sensors frame

Enable **Settings → Cards & order → All readings in one card (HW Sensors)** to place the original per-device sections inside one outer surface. This preserves the selected design, labels, hardware names, instruments, selected/custom readings, device identities and history. It does not invent one aggregate main number or merge physical sensors.

The existing one-to-four-column layout and text/icon visibility and sizes remain available. Warning borders move to the shared perimeter. Disable the option to restore separate outer widget frames. This option is off by default.

Text-size reset restores sizes, preserving visibility. Show all text restores the text roles and hardware icons while preserving sizes. Hardware names can be edited in Devices & readings. Background opacity affects surfaces, not foreground text.

The Sidebar starts and restores from its notification-area icon. Actual executable/configuration and startup paths are visible in System information. Review startup after relocating the portable EXE. Sensor source changes are performed by the single worker, closing the previous backend before opening the next.

See README.md for customization and sensor requirements, and VALIDATION.md for the test scope.
