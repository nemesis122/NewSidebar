# Sidebar by NemeSIS v3.01.4.0

Portable Windows x64 hardware-monitor Sidebar. **EXE and matching source ZIP are both attached.** A small polish release for the glass layouts.

## Fixed

- **Link capsule:** the fill now shows the exact share of the link in use, without a minimum stub. When the link is idle the capsule stays empty and the "Link" label is fully readable.
- **Fill edge:** the bright edge at the liquid level fades out across the middle of the capsule, where the reading sits, so it no longer runs through digits (for example a CPU clock of 4.80 GHz).

Included from earlier v3.01 updates: six glass layouts, temperature as the large number for CPU, GPU and drives, precise voltages, clocks, memory sizes and link speeds, and a reset button on every settings page.

## Download and update

Download **Sidebar-by-NemeSIS-v3.01.4.0.exe** for the portable app. **Sidebar-v3.01.4.0-Source.zip** is the matching source. Close the previous instance and keep `aurora-settings.json` beside the chosen EXE; your settings carry over unchanged. The EXE is unsigned. See **VALIDATION.txt** and **SHA256SUMS.txt** for test scope and integrity.
